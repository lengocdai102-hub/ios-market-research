# iOS 副业调研 · 美区 App Store 可行性分析

> 一份**可复核**的独立开发者方向调研。所有数字都能在 `数据/` 下找到对应文件与字段。
> 采集时间：2026-11-09 ~ 2026-11-11 ｜ 交叉核验：**9/9 PASS**

---

## 一句话结论

**能做，但不是靠「个人开发者做 App」这件事本身赚钱 —— 94% 的个人开发者拿到的是 0.16% 的评分量。真正可行的是：用一个已被验证的付费场景（订阅/买断）+ 一个明确的付费触发点（导出/备份/多设备），而不是做一个大而全的 RV 工具。**

## 核心发现

### 1. 这是巨头市场

11,841 个 app 里，**公司主体 6,729 个（56.8%）垄断 97.84% 的评分数**。
个人开发者 916 个（7.7%），合计 414,446 条评分，占全池 **0.16%**。
评分 TOP15 中**个人开发者数量为 0**。

### 2. 钱在订阅，不在单次

809 个 app 的 IAP 价格解析：中位价 **12.99**，最高 **999.99**，最常见 **9.99** 与 **4.99**。
单次买断的付费天花板明显低于订阅。

### 3. 近 12 个月的新进入者几乎拿不到评分

10,312 个候选池中，近 12 个月新进入者 **203 个（22.7%）**，仅获得全池 **0.02%** 的评分。

### 4. 有「高价值僵尸位」

43 个停更超过一年但仍有 **≥500 评分**的 app —— 需求真实存在，但原开发者已放弃。这是本次调研找到的最明确的切入信号。

### 5. Top 1 方向：RVLogbook

房车/载具维护与保质期日志。纯本地、无服务器、无账号、无第三方 SDK、无网络收集。
